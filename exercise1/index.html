Håkon Wium Lie

The Creator of CSS (Cascading Style Sheets)

About Håkon Wium Lie

Håkon Wium Lie is a Norwegian web pioneer, software engineer, and activist born in 1965. He is best known for proposing the concept of Cascading Style Sheets (CSS) in 1994 while working with Tim Berners-Lee at CERN. His vision transformed the web from plain text documents into visually rich and beautifully styled pages.

Key Life Events

  1. Born in 1965 in Halden, Norway.
  2. Proposed the concept of CSS while at CERN in 1994.
  3. Joined W3C (World Wide Web Consortium) to lead the development of CSS standards.
  4. Received a Ph.D. from the University of Sydney in 2005.
  5. Served as Chief Technology Officer at Opera Software for over a decade.

Major Contributions & Innovations

  • Invented and co-authored the original CSS specification.
  • Pioneered the concept of style sheets separating document content from design.
  • Promoted web standards, accessibility, and open web technologies.
  • Advocated for acid tests to improve browser standard compliance.
