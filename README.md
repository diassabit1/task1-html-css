## 📂 Project Structure & Tasks

* **Task 1: Personal Webpage (`index.html`)**  
  * Profile card featuring an image, name, group, and personal bio.
  * Lists (ordered & unordered), semantic headings, paragraphs, and custom CSS styling (selectors, colors, fonts, margins, padding, and borders).

* **Task 2: Webpage Layout using Floats (`task2.html`)**  
  * Built using pure `<div>` elements and CSS positioning/floats (no Flexbox or Grid).
  * Consists of a Header, Navigation bar, Left Sidebar menu, Right Aside content area, and Footer.

* **Task 3: Tribute Page (`exercise1/index.html`)**  
  * Dedicated tribute page for *Håkon Wium Lie* (Creator of CSS).
  * Includes local images, biographical overview, key life events (ordered list), major contributions (unordered list), and styled external links/buttons.

* **Task 4: Tables and Forms (`task4.html`)**  
  * **Student Grades Table:** Styled HTML table with custom headers, cell borders, alternate row backgrounds (`nth-child`), `.highlight-row` class for a specific student, and `rowspan` usage.
  * **Feedback Form:** Interactive feedback form containing text inputs, email field, select dropdown, radio buttons, textarea, and a styled submit button.
